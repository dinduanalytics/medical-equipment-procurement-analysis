# Project Brief — Medical Equipment Procurement Analysis

**Project owner:** Nwaba Chimdindu  
**Purpose:** Explore procurement efficiency, cost management, supplier performance, and equipment lifecycle management across hospitals.

## Dataset field descriptions

| Field | Description from the supplied data description |
|---|---|
| Hospital | Name of the hospital where the equipment is installed. |
| State | The state in which the hospital is located. |
| Location | Specific location within the hospital where the equipment is installed. |
| Department | The department within the hospital that uses the equipment. |
| Equipment | Name or type of the medical equipment. |
| Quantity | Number of units of the equipment. |
| Unit Price (USD) | Cost per unit of the equipment. |
| Supplier | Company supplying the equipment. |
| Supplier Contact | Supplier contact person. |
| Supplier Phone | Supplier telephone number. |
| Supplier Email | Supplier email address. |
| Supplier Country | Country where the supplier is located. |
| Date Ordered | Date on which the equipment was ordered. |
| Date Delivered | Date on which the equipment was delivered. |
| Warranty Period (Months) | Warranty period provided for the equipment. |
| Maintenance Cost (USD/year) | Annual maintenance cost for the equipment. |
| Installation Cost (USD) | Cost of installing the equipment. |
| Equipment Condition | Current condition of the equipment. |

## Analysis questions from the supplied brief

1. Which Hospitals Spend the Most on Equipment Procurement?
2. What is the Distribution of Equipment by Condition Across Different Departments? The brief says this can help identify areas needing upgrades.
3. How Do Maintenance Costs Vary by Equipment Type? The brief asks to identify the most and least costly types to maintain.
4. What is the Average Delivery Day for Equipment from Different Suppliers?
5. Which States Have the Highest Installation Costs for Medical Equipment?
6. What is the Proportion of Distribution of Equipment Suppliers by Country? The brief frames this as a way to understand global sourcing.
7. How Does Equipment Condition Vary with Installation Costs?

The supplied brief states that these questions can support analysis of procurement efficiency, cost management, supplier performance, and equipment lifecycle management.
